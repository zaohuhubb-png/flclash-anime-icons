# FlClash Anime Icon Pack

Original anime-style icon set inspired by the reference image.

## Files
- `auto.png` — automatic selection
- `manual.png` — manual selection
- `fallback.png` — fallback / failover
- `global.png` — global mode
- `direct.png` — direct connection
- `hong-kong.png`, `taiwan.png`, `japan.png`, `usa.png`, `singapore.png`
- `uk.png`, `canada.png`, `australia.png`, `germany.png`, `france.png`

## Use
These are individual 512×512 PNG images. Upload this folder to a public GitHub repository if you want to serve the images through raw GitHub URLs. Then configure the icon URL/path in FlClash using the format supported by your installed version or your icon-set configuration.

Note: this first pack uses square crops from a contact sheet, so the white background is retained. It is a visual starter pack, not yet a verified FlClash configuration. Confirm the icon-set format and URL rules for your FlClash version before importing.
